# About Us

**Openmukti Audiobook Maker — Version 1**

**Developer: Aishik Dutta**  
**Role: Open-source developer and project creator**

Openmukti Audiobook Maker is an open-source project that helps users create narrated audio and illustrated audiobook videos from text and ebooks. Features include desktop and command-line interfaces, multilingual Piper voices, story-character voice profiles, and bulk audiobook conversion.

The application source is provided under the MIT license. It uses independently developed external tools such as FFmpeg and Piper and does not claim ownership of third-party speech models or licenses.
